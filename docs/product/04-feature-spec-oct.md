# Feature spec: October additions

Agreed 11 Oct 2026, built by the team before the 16–17 Oct freeze. All features follow the existing rules: one service layer used by both the screens and the AI tools, roles checked on the server, no payments, simulated parts labelled, and Gemini only reads, observes and writes text while every decision is made in code.

**Owner decisions (11 Oct):** breeder verification collects **no ID documents or selfies** (no Aadhaar/PAN, no face matching); the care companion keeps the strict rule that the AI **never names medicines or doses**.

| # | Feature | Who | What it does | Simulated | Status |
|---|---|---|---|---|---|
| F14 | **Seller analytics** | Seller | Dashboard charts for the last 8 weeks: views per week; enquiries, visit requests and sales per week; a view-to-sale funnel; sales value per week and by species. SVG charts with hover values and "View as table". Built from events (view, enquiry, visit, sale) recorded on the seller's listings. | The demo seller's 8-week history (labelled "Sample history") | ✅ Built 11 Oct |

Compatibility % for each species is **calculated in code** from the same rules as the quiz: species the rules exclude score 0 with the rule's reason. % badges on pet cards. | — | ✅ Built 11 Oct |

| F18 | **Visits and purchase** | Both | The buyer books a visit (date in the next 30 days, morning/afternoon/evening). The seller confirms or declines. | F19 | **Vaccination card** | Seller | Optional vaccination card in the sell flow; Gemini reads it and the trust score adds a check: a readable record passes, a file that is not a vaccination record costs 10 points, a missing record for a dog or cat becomes a question to ask. | — | ✅ Built 11 Oct |
| F20 | **Pet care companion** | Customer | Account → My pets after a purchase: a daily log (food, play, notes, optional food photo) with Gemini feedback and a streak; the 14-day plan as a checklist; a growth tracker against typical weight ranges; a general vaccination and deworming calendar; a symptom checker that gives urgency (emergency / vet soon / monitor) and always points to a vet. Never a diagnosis, medicine name or dose. | — | ✅ Built 11 Oct |
| F21 | **One-time code and Google sign-in** | Both | Login with a code sent to an email or mobile number, only for **new** accounts and the demo accounts (the code is shown on screen in this demo, so it must never open an existing account). **Continue with Google** via Firebase Authentication; the server verifies the Firebase ID token and links the account by email.
